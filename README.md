# proxykhan.github.io

Personal portfolio of **Mohammed Azhar Khan**, AI / Machine Learning Engineer.

**Live:** https://proxykhan.github.io

A single static page (HTML, CSS and vanilla JavaScript, no build step) served by GitHub Pages.

## Structure

```
index.html                         page content and case-study dialogs
assets/css/style.css               styles, dark and light themes
assets/js/main.js                  theme toggle, menu, scroll effects, counters, hero animation
assets/img/                        portrait and project images
assets/Mohammed-Azhar-Khan-Resume.pdf
```

## Updating

Edit `index.html` (all text lives there), commit and push to `main`. GitHub Pages republishes in about a minute.

To preview locally, serve the folder with any static server, for example:

```bash
python -m http.server 8000
```
